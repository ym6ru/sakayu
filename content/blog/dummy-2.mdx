（ダミーの日記です）公開して半年ほどたったブログを、Next.js から Astro と素の CSS に作り直しています。記事が数本しかないブログに、数百KBの JavaScript を配信していたことに気づいたのがきっかけでした。

## なぜ素の CSS にしたか

最近の CSS は、入れ子やカスタムプロパティがブラウザの標準で使えます。トークンの数も少ないので、ビルドの仕組みを持たないほうが長く運用しやすいと考えました。

## 気をつけていること

新しい技術を使うことより、ページがすぐに開いて、文字が読みやすいことを大切にしています。
